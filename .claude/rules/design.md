# Design Rules

- Ensure pixel-perfect matching with the reference image.
- Use spacing (padding/margin) multipliers consistent with Tailwind's 4px grid.
- Match exact typography (font families, weights, sizes, and line heights).
- Extract and use exact hex colors and gradients from the design reference.
- Pay close attention to subtle design elements: borders, border-radii, drop shadows, and opacity.
- Maintain consistent alignment and positioning of elements as shown in the reference.
- Design should be fully responsive (ensure it works across screen sizes).
